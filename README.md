## 🔬 Research & Publications

### Real-Time Unsupervised Astronomical Anomaly Detection in Large-Scale Sky Surveys

**Research status:** Manuscript in Preparation – IEEE Conference Format Draft Completed

**Research focus:**
CBAM-Enhanced Convolutional Autoencoders and Latent Isolation Forests.

Developed a hybrid unsupervised deep learning architecture integrating:

- Convolutional Block Attention Module (CBAM) Autoencoder
- Latent-Space Isolation Forest

**Research Results:**

| Evaluation Metric | Result |
|---|---:|
| ROC-AUC | 0.8592 |
| Precision | 89.94% |
| F1-Score | 0.8496 |
| Inference Latency | 39.36 ms/image |
| Improvement over non-attention baselines | +6.09% |

The architecture was designed to identify rare celestial outliers without requiring spectroscopic labels.
